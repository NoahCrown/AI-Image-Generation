# Contributing to AI-Image-Generation

Thank you for your interest in contributing! Please follow these guidelines to help us maintain a high-quality, collaborative project.

## How to Contribute

1. **Fork the repository** and clone your fork locally.
2. **Create a new branch** for your feature or bugfix:
   ```
   git checkout -b feature/your-feature-name
   ```
3. **Make your changes** with clear, well-documented code.
4. **Test your changes** locally.
5. **Commit** with a descriptive message (see below).
6. **Push** your branch to your fork.
7. **Open a Pull Request** against the `main` branch of this repository.

## Coding Style

- Use ESLint for the client code (`client/.eslintrc.cjs`).
- Write clear, modular, and well-commented code.
- Use descriptive variable and function names.
- Add docstrings/comments for complex logic and all exported functions/components.

## Commit Messages

- Use clear, concise commit messages.
- Format: `<type>: <short description>`
  - Example: `fix: handle API error in image generation`
  - Types: `feat`, `fix`, `docs`, `style`, `refactor`, `test`, `chore`

## Branch Naming

- Use `feature/`, `fix/`, or `chore/` prefixes.
  - Example: `feature/add-user-auth`, `fix/image-download-bug`

## Issues and Pull Requests

- Reference related issues in your PR description.
- Fill out the PR template.
- Ensure your code passes linting and does not break existing functionality.
- Be responsive to code review feedback.

## Code of Conduct

By participating, you agree to abide by the [Code of Conduct](CODE_OF_CONDUCT.md) (to be added).

## Need Help?

Open an issue or start a discussion in the repository.

Thank you for contributing!
