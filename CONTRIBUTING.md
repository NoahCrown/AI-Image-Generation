# Contributing to AI-Image-Generation

Thank you for your interest in contributing! We welcome all contributions to improve this project.

## How to Contribute

1. **Fork the repository** and clone your fork locally.
2. **Create a new branch** for your feature or bugfix:
   ```
   git checkout -b feature/your-feature-name
   ```
3. **Make your changes** with clear, descriptive commit messages.
4. **Ensure code style** by running ESLint and Prettier (for JavaScript/React code).
5. **Test your changes** before submitting a pull request.
6. **Push to your fork** and submit a pull request (PR) to the `main` branch.

## Code Style

- Use [ESLint](https://eslint.org/) and [Prettier](https://prettier.io/) for code formatting.
- Write clear, descriptive variable and function names.
- Add comments to explain complex logic.
- Keep functions small and focused.

## Branch Naming

- Use `feature/your-feature-name` for new features.
- Use `bugfix/your-bug-description` for bug fixes.
- Use `docs/your-doc-description` for documentation updates.

## Pull Request Process

- Describe the purpose of your PR and the changes made.
- Reference related issues if applicable.
- Ensure your branch is up to date with `main`.
- One feature or fix per PR.

## Reporting Issues

- Use the [GitHub Issues](https://github.com/NoahCrown/AI-Image-Generation/issues) page to report bugs or request features.
- Provide as much detail as possible.

## Code of Conduct

Please be respectful and inclusive. See [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) if available.

Thank you for helping make AI-Image-Generation better!
